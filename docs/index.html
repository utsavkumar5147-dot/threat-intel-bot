Threat Intel Bot

Automated Threat Intelligence & IOC Enrichment Bot

About the Project

Threat Intel Bot is a Python-based cybersecurity project that automates indicator-of-compromise investigations, threat intelligence enrichment, risk scoring, and monitoring.

Key Features

  • IOC classification and risk scoring
  • VirusTotal and AbuseIPDB integration
  • Automated IOC monitoring
  • Flask-based SOC dashboard
  • Security notifications and Gmail API email alerts

Google API Usage

Gmail authorization is used to send security alert emails from the account authorized by the user. The application does not request permission to read Gmail messages.
