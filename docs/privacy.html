Privacy Policy

Application: Threat Intel Bot

Last updated: October 24, 2026

1. About This Application

Threat Intel Bot is a cybersecurity automation project for IOC investigation, threat intelligence enrichment, risk monitoring, and security notifications.

2. Google Account Access

The application requests the Gmail send permission (https://www.googleapis.com/auth/gmail.send) to send cybersecurity alert emails from a Google account authorized by its user.

The application does not request Gmail inbox reading, email deletion, or mailbox management permissions.

3. Data Collected and Processed

The locally running application processes IOC indicators, investigation results, risk scores, monitoring events, and notification records.

Sender and recipient email addresses are configured locally for alert delivery.

4. Data Storage and Security

Google OAuth credentials and authorization tokens are stored in local configuration files with restricted filesystem permissions.

Investigation results and notification records are stored locally. These local files are excluded from the project's Git repository.

Local filesystem permissions are not equivalent to encryption at rest.

5. Data Sharing

The application sends authorized email messages through the Gmail API. IOC indicators may be submitted to configured third-party threat intelligence services, including VirusTotal and AbuseIPDB, when external investigation is enabled.

Google account authorization tokens are not intended to be shared with these threat intelligence providers.

Google user data is not sold or used for advertising.

6. Data Retention and Deletion

Local investigation history and notification records remain on the user's device until removed by the user or application maintenance procedures.

Users can remove locally stored authorization files and revoke Google account access through their Google Account security settings.

7. Google API Services User Data

Use of information received from Google APIs follows the Google API Services User Data Policy, including applicable Limited Use requirements.

8. Contact

For questions about this project or its privacy practices, contact the project maintainer through the GitHub repository.
